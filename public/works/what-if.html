ПОЛЕВЫЕ ЗАМЕТКИ / 01—03
01Почему буквы помнят, где их дом?+

Браузер рисует текст на скрытом холсте. Мы считываем его пиксели и превращаем их в частицы. У каждой есть домашняя координата. В режиме «Форма» к ней тянет пружина — поэтому разрушенные буквы умеют собираться обратно.

// Сила возвращения домой
ax = (homeX - x) * spring;
ay = (homeY - y) * spring;

// Скорость + сопротивление
vx = (vx + ax * dt) * drag;
x += vx * dt;
02Перемотка — это настоящая история?+

Да. Двадцать раз в секунду записываются координаты и скорости всех частиц, режим физики и время симуляции. Кольцевой буфер хранит последние 7,5 секунды. Перемотка воспроизводит эти состояния назад с двойной скоростью. Отпускаешь кнопку — создаёшь новую ветку событий.

// Снимок реального состояния
frame[i] = [x, y, vx, vy];

// Назад по кольцевому буферу
head = (head - 1 + capacity) % capacity;
restore(history[head]);
03Что ещё можно попробовать?+

Напиши своё имя. Включи гравитацию. Подбрось частицы взрывом. Удерживай указатель над ними, чтобы собрать облако. Запусти вихрь, сохрани абстрактный постер и отмотай всё назад. Здесь нет правильного результата.

1 / 2 / 3  →  форма / падение / вихрь
B          →  импульс
R держать  →  назад во времени
Space      →  пауза
P          →  сохранить PNG
