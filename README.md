# Lumen Studio — сайт студии разработки

Промо-сайт студии, которая делает сайты, веб- и мобильные приложения, программы и ботов.
Концепция — «код как живая материя»: облако из 72 000 частиц (16 000 на мобильных) перетекает между
формами `</>` → браузер → смартфон → чип → сфера и сопровождает посетителя по всем секциям.

## Стек

- Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4
- three.js + @react-three/fiber + drei + postprocessing (Bloom, хроматическая аберрация, виньетка)
- GSAP 3.15: ScrollTrigger, SplitText, Flip, Draggable, Inertia, ScrambleText
- Lenis для плавного скролла
- Собственные GLSL-шейдеры частиц (морфинг, flow-noise, отталкивание от курсора, закрутка)

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
npm run build && npm start
npm run typecheck
```

Скопируйте `.env.example` в `.env.local` и при необходимости заполните:

| Переменная | Зачем |
| --- | --- |
| `NEXT_PUBLIC_SITE_URL` | канонический адрес для SEO, Open Graph и sitemap |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | заявки из брифа приходят в Telegram; без них API принимает заявку и в dev-режиме пишет её в консоль |

## Деплой на Vercel

1. Импортируйте репозиторий на [vercel.com/new](https://vercel.com/new), фреймворк определится автоматически.
2. Добавьте переменные окружения из таблицы выше.
3. Deploy. Команды по умолчанию (`npm install`, `next build`) менять не нужно.

## Где что менять

- `data/` — весь контент: студия и контакты (`site.ts`), услуги, этапы, избранные работы (`cases.ts`), живые примеры (`works.ts`), тарифы, отзывы, FAQ, технологии.
  Название, цены и контакты сейчас — правдоподобные заглушки.
- `public/works/` — все демо-проекты: каждый — самостоятельный HTML-файл. Превью лежат в `thumbs/` (16:10),
  кадры для галереи кейса — в `shots/имя-1.webp` и `shots/имя-2.webp`, экраны 3D-телефона и ноутбука — в `textures/`.
  Чтобы добавить работу, положите `имя.html` и картинки, затем допишите запись в `data/cases.ts` или `data/works.ts`.
  Демо открываются в `iframe` с `sandbox`: скрипты работают, но доступа к основному сайту у них нет.
  Если демо пишет в `localStorage`, оберните вызов в `try/catch`: в песочнице хранилище недоступно.
- `components/sections/` — секции страницы по порядку, `components/layout/` — прелоадер, хедер с меню, футер, рамка.
  Номера секций («06 / 13») считаются автоматически из `sections` в `data/site.ts`.
- `components/three/` — WebGL-сцена: `Particles.tsx` (морфинг), `shapes.ts` (генераторы форм),
  `layouts.ts` (позиция, масштаб и форма облака для каждой секции), `Devices.tsx` (3D-смартфон и ноутбук), `GlassCore.tsx`.
- `shaders/` — GLSL, `hooks/` — `useLenis`, `useMagnetic`, `useCursor`.
- Контурные надписи (`.text-outline`, бегущая строка, заголовок заявки, пункты меню) набраны статическим начертанием
  `app/fonts/unbounded-outline-500.woff2` без наложенных контуров. Пересобрать его:
  `uv run --with fonttools --with skia-pathops --with brotli python scripts/build-outline-font.py`.

## Производительность и доступность

- Один WebGL-контекст на весь сайт. 3D-модели и облако привязываются к DOM-плейсхолдерам через проекцию координат.
- `PerformanceMonitor` снижает DPR и отключает постобработку на слабых устройствах, на мобильных частиц в 4,5 раза меньше.
- `prefers-reduced-motion`: нет Lenis, прелоадера, пина и морфинга по скроллу, анимации сведены к минимуму.
- Текст отрисовывается на сервере и виден без WebGL и JS. Семантические секции, фокус-стили, `aria` для меню, модалки и аккордеона.
- Прелоадер показывается один раз за сессию (`sessionStorage`).
